## Projetos em destaque

### 01 · Data Lakehouse

Arquitetura de dados desenvolvida para processamento, organização e disponibilização de informações analíticas, com camadas **Bronze, Silver e Gold** e separação entre as responsabilidades de cada componente.

| Camada da solução | Tecnologia / abordagem |
| --- | --- |
| Armazenamento | Object Storage |
| Processamento | Apache Spark / PySpark |
| Formato das tabelas | Apache Iceberg |
| Catálogo | Apache Polaris |
| Consulta | Trino |
| Orquestração | Apache Airflow |

**Apresentação pública:** [Ver projeto no portfólio][projeto-lakehouse]. Código privado não disponibilizado.

### 02 · Portal Analytics

Plataforma de aplicações web analíticas que disponibiliza dashboards, consultas e informações analíticas por meio de interfaces web, centralizando o acesso aos dados para apoiar análises e decisões de negócio.

**Tecnologias:** Python · Pandas · Flask · Dash · Plotly · SQL

**Projeto ou demonstração:** [Ver projeto no portfólio][projeto-python].

### 03 · Análise de Evasão Escolar

Projeto acadêmico de análise exploratória de dados e investigação de fatores relacionados à evasão escolar, com organização e visualização das informações para apoiar a compreensão do tema.

**Tecnologias e métodos:** Python · Pandas · Análise exploratória de dados · Visualização de dados

**Projeto ou apresentação:** [Ver projeto no portfólio][projeto-evasao].

**Portfólio profissional:** [acessar portfólio][portfolio].
